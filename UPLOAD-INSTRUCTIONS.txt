MOBILE UPLOAD
1. Extract the ZIP on your phone.
2. In github.com/mowolf/tools select Add file > Upload files.
3. Select ALL extracted files together and commit to main. All files belong at the repository root; there are no folders. Replace existing files with these versions.
4. Settings > Pages > Deploy from a branch > main > / (root) > Save. No workflow is needed.
5. After deployment, reload the site. If an old version persists, open a private browser tab.

The engine downloads about 32 MB from cdn.jsdelivr.net when first used. Videos stay on your device. Browser conversion has not been verified in this environment. Smaller videos work best on phones.
